# Landing Page — Reforma Tributária no Simples Nacional

Landing page de vendas do curso ao vivo **"Reforma Tributária – Foco Simples Nacional"**, de Rômulo Albuquerque / FiscoSim.

Página estática (HTML + CSS + JS), sem build, pronta para deploy na Vercel.

## Estrutura

```
index.html      → página completa
styles.css      → design system (cores da marca FiscoSim, responsivo, animações)
script.js       → accordions, scroll reveal, header sticky, barra mobile de compra
assets/         → logo (SVG) e foto hero
```

## Deploy

Projeto estático — a Vercel serve a raiz do repositório automaticamente, sem configuração de build.
